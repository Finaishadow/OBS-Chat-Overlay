Before you begin

What you're building

Your browser-based overlay listens to live chat through Streamer.bot's local WebSocket server and draws temporary chat bubbles inside OBS. The guide website is separate from the overlay you stream with.

1 · OBS StudioYour streaming software. It displays a transparent Browser Source over your gameplay.
2 · Streamer.botConnects your streaming account and emits Twitch, Kick and YouTube chat events.
3 · Three filesHTML creates the page, JavaScript processes messages, and CSS controls their appearance.
This walkthrough primarily targets Windows. Streamer.bot's macOS and Linux support is experimental. You will also need a streaming account and internet access.
Part one

Install and connect everything

Start from a blank PC setup and finish with a running Streamer.bot WebSocket server.

01

Install OBS Studio

  1. Download OBS from the official OBS website.
  2. Install and launch OBS, then complete the auto-configuration wizard if it appears.
  3. In the Scenes dock, create or select the scene that will display your chat.
02

Install Streamer.bot

  1. Download the latest stable Windows ZIP from streamer.bot.
  2. Extract the ZIP to a permanent folder, such as C:\Streamer.bot\.
  3. Run Streamer.bot.exe. There is no traditional installer.
Avoid storing Streamer.bot in cloud-synced folders and avoid launching it as administrator.
03

Connect your streaming account

Within Streamer.bot, connect whichever platform(s) you use:

  • Twitch: Platforms → Twitch → Accounts → sign in with your broadcaster account.
  • YouTube: Platforms → YouTube → Accounts → sign in with Google and enable Auto Connect. For real chat, it must monitor an active live broadcast.
  • Kick: Platforms → Kick → complete the Kick-specific setup; it requires Streamer.bot v1.0.0+ and its website integration.

Connect only the platforms you need; you do not need all three.

04

Enable Streamer.bot's WebSocket server

  1. Open Servers/Clients → WebSocket Server.
  2. Set host/address to 127.0.0.1, port to 8080, and endpoint to /.
  3. Enable Auto Start and click Start Server if required.
  4. For this local-only example, leave enforced authentication off, or configure a matching private password locally.
Host:       127.0.0.1
Port:       8080
Endpoint:   /
Auto Start:  On
Do not expose the WebSocket server to the public internet such as port forwarding. OBS's separate WebSocket server (typically port 4455) is not the one used by this chat overlay.
Part two

Put the overlay in OBS

You don't need to install any custom OBS plugin. All three files are used together as a local web page.

05

Download the project files

  1. Visit this project's GitHub repository and choose Code → Download ZIP.
  2. Extract the archive and open the overlay folder.
  3. Copy its three files to a folder that will stay on your computer.
C:\OBS-Chat-Overlay\
├── index.html
├── overlay.js
└── style.css
Important: Use overlay/index.html inside OBS, not this public tutorial's docs/index.html.
06

Check the JavaScript configuration

Open overlay.js in Notepad or VS Code. The default settings match Streamer.bot's local WebSocket server:

const MAX_MESSAGES = 8;
const MESSAGE_LIFETIME = 8000;
const DEMO_MODE = false;

const WEBSOCKET_OPTIONS = {
  host: "127.0.0.1",
  port: 8080,
  endpoint: "/",
  subscribe: {
    Twitch: ["ChatMessage"],
    Kick: ["ChatMessage"],
    YouTube: ["Message"],
    General: ["Custom"],
  },
  logLevel: "info",
};

Save any edits. Keep passwords, tokens and personal SSN session IDs out of your public GitHub copy.

07

Add a Browser Source in OBS

  1. Choose your scene, then go to Sources → + → Browser.
  2. Name it Custom Chat Overlay and check Local file.
  3. Click Browse and choose your local index.html from the overlay folder.
  4. Start with Width 800 and Height 600. Resize later for your scene.
  5. Leave the Custom CSS field empty. Your overlay already loads style.css automatically, so there is only one place to maintain the design.
  6. Move this source above your gameplay/video source and position it in the preview.
Messages appear at the bottom-left of the Browser Source. Its width, height and placement determine where they appear on the stream.
08

Test the overlay

First, try demo mode: change const DEMO_MODE = false; to true, save overlay.js, and refresh your Browser Source. Sample messages will appear without you needing to go live.

Then try real chat: return demo mode to false, refresh, ensure Streamer.bot is running, and send a real chat message to your connected Twitch/Kick channel or active YouTube live chat.

No Streamer.bot Action is necessary for basic chat messages. The overlay subscribes to the built-in chat events.
Part three

Customize the experience

09

Change fonts, size, colors and avatars

At the top of style.css, customize the variables below, save, then refresh your OBS Browser Source:

:root {
  --chat-max-width: 500px;
  --chat-font-size: 24px;
  --chat-username-size: 28px;
  --chat-background: rgba(0, 0, 0, 0.70);
  --chat-spacing: 15px;
  --avatar-size: 60px;
  --animation-duration: 7s;
}

Only one CSS file needed. Edit overlay/style.css, save, and refresh your OBS Browser Source. The same file controls dark rounded chat bubbles, avatars, Comfortaa, and the 7-second bounce-in/slide-out animation. JavaScript removes each message after 8 seconds by default, so the CSS exit animation finishes first. Leave OBS's Custom CSS field empty to avoid conflicting settings.

Change left: 20px and bottom: 20px in the .chat CSS rule to move chat within the source. JavaScript's AVATAR_MODE controls whether profile pictures or platform icons display.

Twitch starts with a platform icon; Twitch profile pictures require a separate custom avatar event. Kick and YouTube can use profile image URLs supplied in chat events.

09A

Optional: Show real Twitch profile pictures (Streamer.bot C#)

To show a chat user's actual Twitch avatar, create an action in Streamer.bot. This action sends avatar information only; your normal Twitch chat subscription continues to show the messages.

  1. Open Actions in Streamer.bot and create an action named OBS Chat — Twitch Avatars.
  2. Add the Twitch → Chat Message trigger.
  3. Add Twitch → Get User Info for Target with User Login set to %userName%.
  4. After that sub-action, add Execute C# Code and paste the script shown below (also in streamerbot/twitch-avatar.cs in the GitHub download).
  5. Compile and save. Make sure Streamer.bot's WebSocket server is running, then send a Twitch message and watch OBS.
using System;
using Newtonsoft.Json.Linq;

public class CPHInline
{
    public bool Execute()
    {
        CPH.TryGetArg("targetUserId", out string userId);
        CPH.TryGetArg("targetUserProfileImageUrl", out string avatarUrl);

        if (string.IsNullOrWhiteSpace(userId) || string.IsNullOrWhiteSpace(avatarUrl))
        {
            CPH.LogWarn("Missing targetUserId or targetUserProfileImageUrl");
            return true;
        }

        var payload = new JObject
        {
            ["type"] = "avatar",
            ["platform"] = "twitch",
            ["userId"] = userId,
            ["avatar"] = avatarUrl
        };

        CPH.WebsocketBroadcastJson(payload.ToString(Newtonsoft.Json.Formatting.None));
        CPH.LogInfo("Broadcast Twitch avatar for userId=" + userId);
        return true;
    }
}
Order matters: Get User Info for Target must run before the C# code; it supplies %targetUserId% and %targetUserProfileImageUrl%. Without it, the script will log a warning and send nothing. If your Twitch icon never changes, review Streamer.bot's Action History and WebSocket server settings.

How it works: the code broadcasts an avatar JSON message. Your overlay receives it through the General.Custom event, associates it with the Twitch user ID and updates the displayed message. An icon may appear briefly while the profile image is being fetched. Keep AVATAR_MODE = "logoFallback" or "profileFirst" in overlay.js.

This extra C# action is only needed for Twitch profile pictures, not for basic Twitch, Kick or YouTube chat text. See the Streamer.bot Get User Info for Target documentation for the variable names.

10

Optional: Add TikTok or Instagram via Social Stream Ninja

  1. Set up Social Stream Ninja and its supported browser extension/sources.
  2. Locate your personal SSN session ID.
  3. Enable its remote API control and Send chat messages to API server settings, following the official instructions.
  4. In your private local overlay.js, set SSN_ENABLED = true and paste your personal SSN_SESSION_ID.
  5. Save and refresh OBS; the overlay listens on SSN WebSocket channel 4.
const SSN_ENABLED = true;
const SSN_SESSION_ID = "YOUR_PERSONAL_SESSION_ID";
Do not upload your actual SSN session ID to public GitHub. Avoid sending the same YouTube messages through both SSN and Streamer.bot, or you'll see duplicates.
11

Finish your on-stream layout

  1. With real or demo messages showing, position the Browser Source on your stream scene.
  2. Adjust size, padding and font until text is legible against your footage.
  3. Turn off demo mode before your broadcast.
  4. Save your scene collection and start your stream using your regular OBS workflow.

By default, the overlay keeps up to eight messages and removes each after eight seconds. Change those values in overlay.js if you'd like.

Troubleshooting

Something not showing up?

These are the common beginner issues. Check demo mode first; it tells you whether the display works independently of live chat.

Display problems

  • No bubbles at all: enable demo mode, save, and refresh the source.
  • Chat is clipped: make the OBS Browser Source bigger.
  • Too small or large: change the CSS variables.
  • Client library error: confirm internet access to jsDelivr.

Connection problems

  • Disconnected: start Streamer.bot's WebSocket server; check host, port and endpoint.
  • Connected, no chat: sign in to the streaming platform and verify events are arriving.
  • Kick delays: webhook delivery can be delayed.
  • Duplicates: disable one of the overlapping SSN / Streamer.bot sources.
Do I need OBS's WebSocket server, too?

No. It is optional for this overlay. OBS's WebSocket server is for apps controlling OBS. Your custom HTML overlay uses Streamer.bot's WebSocket server, typically at 127.0.0.1:8080.

Can I paste the GitHub Pages address directly into OBS?

This guide deliberately uses a local file in OBS. A hosted HTTPS page connecting to a local, non-TLS WebSocket has browser security/network constraints and is not the recommended beginner setup. Download the overlay's three files and select the local index.html instead.

Will Twitch, Kick, YouTube, TikTok and Instagram all work automatically?

No. Streamer.bot must be connected to your chosen supported platforms and receive their events. TikTok and Instagram use the optional Social Stream Ninja connection, which must be configured separately. Custom Twitch avatar images also need an additional custom event.

Can I share or customize these files?

Yes, you can customize files on your computer. If you publish your own fork, decide on an appropriate license and avoid committing secrets such as passwords, tokens and personal session IDs.
